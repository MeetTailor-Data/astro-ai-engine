# 🚀 Astro AI Engine — Frontend (React + Vite + Three.js)

## Stack
- React 19 + Vite
- Three.js for 3D rendering
- Tailwind CSS for styling

## Run Locally
```bash
cd frontend
npm install
npm run dev
```

## Structure
- src/components/ — UI screens and Three.js scenes
- src/context/MissionContext.jsx — Global state
- src/services/api.js — Backend API + local physics fallback
- src/utils/missionPhysics.js — Rocket validation physics
